# 種別D 置換リスト初版（v1、2026-10-29 調査）

## 採用基準

項目は思いつきで足さない。追加には次の調査を必須とする。

1. 標準名前空間（ns0）の wikitext を対象に、正規表現検索（`insource:/対象文字列/`）で**正確な出現ページ数**を数える（通常検索はあいまい検索で水増しされるため使わない）
2. 出現文脈をサンプル確認する（10件以下なら全件、多い場合は最低8件）。**引用・原文ママ・作品名・その表記自体への言及**が多数を占める項目は採用しない
3. 除外条件を文章で定義できること
4. 実施時は全件 dry-run し、運用者が差分を全件確認してから保存する（このリストの「採用」は自動実行の許可ではない）

## 採用（v1）

### D-01: ウイキペディア → ウィキペディア

- 根拠：「ウィキペディア」の旧来表記／誤表記。現在の正式表記は「ウィキペディア」であり、記事本文で「ウイキペディア」と書く理由は基本的にない
- 実数（2026-10-29、ns0・正規表現検索）：**24ページ**
- 文脈確認：8ページ・11文脈を確認。大半は編集者が書いた注釈・本文中の表記（例：「ウイキペディア内の『○○』の項を参照のこと」という注釈が山岳関係の記事に複数）で、誤表記として修正可能と判断した
- 除外条件（確認できた実例に基づく）：
  - 引用文の中（例：SNS 投稿の引用に含まれる「ウイキペディアは間違っており…」）は直さない
  - HTML コメント（`<!-- -->`）の中は直さない
  - 「ウイキペディア」という表記そのものを論じている文脈は直さない
- 実施方法：対象が最大24ページと少ないため、dry-run の差分を運用者が1件ずつ確認し、上記除外に当たるものはスキップする。想定の実編集数は十数件規模
- 注意：仮運用の目安（40〜200回）に対しては単独では不足する規模。種別Dの仮運用は、後述の追加候補の調査が進んでから、または種別Cの仮運用と併せて審議してもらう想定

いずれも「誤表記らしく見えるが、実際は意図的な表記や引用が多数を占めた」ため。個別に人が判断する場合まで否定するものではない。

## 扱わないもの

- 表記ゆれの統一（例：データー／データ、サーバー／サーバ）は、正誤ではなく編集方針・好みの問題を含むため、この Bot では扱わない
- 歴史的仮名遣い・旧字体そのものは誤りとして扱わない
