### 作業種別と内容

**種別C（リンク等の置換）― メイン**
記事の改名・分割が合意された際に、Wikipedia:Bot作業依頼へ依頼されるリンク修正を行います。依頼に示された「旧名→新名」の対応表の範囲内でのみ、内部リンクのリンク先を置き換えます（`[[旧名]]`、`[[旧名|表示名]]`、`[[旧名#節]]` のリンク先のみを対象とし、表示名・節名・本文は変更しません）。対応表で判断できないケースは置換せず、依頼ページで報告します。

**種別D（誤字・誤表記の修正）― サブ**
文脈に左右されない明らかな誤字・誤表記を、固定した置換リストに基づいて修正します。リストの各項目には根拠と除外条件を付け、初回使用前に dry-run の差分を運用者が全件確認します。引用・固有名詞など誤りとは言えない文脈は対象外です。（置換リスト初版は本申請に添付します ※作成中）

### 運転形態

- 手動制御（半自動）です。起動・停止は常時運用者が行い、自動の定期実行は行いません
- 保存前に dry-run で差分を生成し、運用者が確認してから書き込みます
- 稼働時期：作業依頼への対応時など不定期です。連続運転はしません
- 編集間隔：承認前は 60 秒以上を守ります。承認後も 5 秒以上（混雑時間帯は 20 秒以上を目安）とします
- 問題発生時は直ちに停止し、会話ページ等での連絡に速やかに対応します

### 使用プログラム

Python / Pywikibot 11.9
ソースコード：https://github.com/Arbeit2025/wikipediabot

### 仮運用について

種別Cは WP:BOTREQ の案件から、種別Dは事前合意をいただいた後に、それぞれ 40〜200 回の範囲で仮運用を行い、結果を報告します。
